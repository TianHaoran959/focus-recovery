# 专注回收 Focus Recovery

> 运行在 Chrome 浏览器上的注意力辅助扩展，专为"电脑看网课容易走神"的场景设计。
>
> **不做"网站屏蔽警察"，做"注意力镜子"** —— 用定时元认知自检和页面静止检测，帮你觉察走神、快速回收注意力。

## 为什么做这个

### 痛点
在电脑上看视频课程时容易走神——刷着刷着视频号，半小时一小时就过去了。手机已经放远，但问题是"**人在电脑前，但心不在**"。

### 市场空白
调研了 10+ 款专注工具后发现：

| 类别 | 代表产品 | 核心机制 | 管电脑看课？ | 觉察走神？ |
|---|---|---|---|---|
| 手机 App | Forest / 番茄ToDo / 潮汐 | 游戏化 / 任务 / 白噪音 | ❌ | ❌ |
| Chrome 扩展 | Yellow Tomato / Otto 等 | **网站屏蔽 (blocker)** | 部分 | ❌ |
| 时间追踪 | Clockify / Toggl | 记账 + idle 检测 | 部分 | ❌ |
| **本产品** | **专注回收** | **元认知自检 + 走神回收** | ✅ 专为 | ✅ 核心 |

- **"人在心不在"没人管**：屏蔽网站阻止不了发呆和离开
- **电脑网页学习场景被忽视**：私域网课、MOOC 等场景，手机 App 没用，网站屏蔽容易误伤
- **"堵" vs "疏"**：竞品靠强制屏蔽（堵），本产品靠元认知自检（疏）

### 科学依据
正念/注意力训练核心三能力：选择焦点 → **检测走神（元觉察 meta-awareness）** → 无评判重新定向。神经影像研究显示正念训练改变额顶控制网络；短时训练（4×20 分钟）即可显著改善注意力。

**本产品的"定时是/否自检"正是元觉察训练的产品化。**

## 核心功能

### 🎯 核心计时与自检
- **专注计时**：25/30/45/60 分钟或自定义，后台权威时钟（毫秒时间戳 + chrome.alarms）
- **定时元认知自检**：到点弹出"是/否"自检卡片，2 秒完成操作
- **走神回收流程**：点"否"后选择走神原因（刷手机/发呆/被打断/其他），显示回收引导语
- **提醒话术随机化**：本地话术库随机选取，避免枯燥

### 🟢 悬浮球与网页交互
- **网页右上角悬浮球**：毛玻璃胶囊，显示剩余时间，左键菜单（开始/暂停/结束/设置）
- **悬浮球自愈**：MutationObserver 监听 SPA 路由变化，自动重挂
- **多页面实时同步**：storage.onChanged + 每秒整秒对齐，切页立即对齐（误差 <1 秒）
- **一键刷新所有页面**：扩展更新后一键刷新全部标签页

### 🔍 检测与提醒
- **页面静止检测**：鼠标+画面+焦点三信号融合，静止超 45 秒不计有效时长
- **疑似离开提醒**：静止超 90 秒温和提醒（不自动暂停）
- **全屏三重兜底**：系统通知 + 提示音（默认关）+ 任务栏标题闪烁（不自动退出全屏）
- **网站学习/娱乐统计**：自动识别网站类型，统计学习/娱乐时长占比

### 📊 数据与复盘
- **当日小结**：完成块数、专注率、学习/娱乐时长、高效时段、最常走神原因
- **本周趋势**：每日专注时长柱状图，今日高亮
- **一键导出复盘包**：复制当日数据到剪贴板，粘贴给 AI（豆包）做走神规律分析
- **设置页**：自检间隔、提醒方式、静止阈值、提示音开关、网站分类规则

### 🎨 视觉与交互
- **沉浸自然风**：日落渐变（橘→粉→紫）+ 毛玻璃卡片 + 环形进度
- **扑克牌扇形交互**：4 张牌扇形展开，**鼠标悬停即放大浮到最上层**，选项直接可点（v1.3.2 定稿，去掉了点击摆正步骤）

## 安装方法

### 方式一：加载已解压扩展（推荐，零成本）
1. 下载 `focus-recovery-extension-v1.3.2.zip` 并解压
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹
5. 固定扩展到工具栏，点击图标开始使用

### 方式二：在线 Demo（免安装，HR 体验用）
打开 `focus-recovery-popup预览.html`，即可体验 popup 主界面和扑克牌交互（内置示例数据）。

## 技术栈

- **Chrome Manifest V3**：Service Worker 后台 + Content Script 注入
- **原生 HTML/CSS/JavaScript**：零框架、零构建、零第三方库、零 CDN
- **chrome.storage.local**：纯本地存储，零联网
- **Shadow DOM**：悬浮球和弹窗样式隔离，不被网站 CSS 污染
- **权威时钟**：毫秒时间戳 + chrome.alarms，不受标签页休眠影响
- **CSP 合规**：全部外部 JS 文件，无内联脚本（MV3 硬约束）

---

## 隐私声明

- **零联网**：不发送任何数据到外部服务器，无任何 `fetch`/`XMLHttpRequest` 请求
- **不截屏**：静止检测使用鼠标活动 + 焦点 + 视觉变化信号融合，不使用截屏
- **纯本地**：所有数据存储在 `chrome.storage.local`，仅你本人可访问
- **无账号**：无需注册、无需登录、无需授权任何第三方
- **无遥测**：不收集使用数据、不埋点、不上报崩溃
